# 生息 · Sense Murmur

**创造角色与群像，积累共同经历，延展故事、陪伴、学习与创作。**

《生息》是一款以数字生命为核心的 AI 互动与创作应用。你可以从一段设定、一个故事或一组人物开始，建立角色的性格、关系网与视觉形象，让他们在群聊、私聊、故事、讨论和学习中与你及彼此相处。

共同经历会进入角色的分层记忆，影响关系、情绪和之后的表达；相处过程也会留下日记、信件、动态与日历活动。需要做事时，同一套应用还提供自然语言操作、联网检索、文件处理和可迭代的 Agent 作品。从人物设定到长期相处，从一段交流到一份作品，这些能力可以在同一个项目里衔接使用。

## 从一个设定，建立一组人物

角色创作既支持逐项编辑，也支持 AI 生成与批量补全。可以先写一句人物描述，也可以提供故事、剧本或对话，让系统提取人物名单、身份和关系线索，选好阵容后再生成完整角色。

- **人物内核：** 背景、专长、核心欲望与恐惧、价值排序、自我认知、依恋与冲突方式。
- **表达差异：** 人格与行为参数、口头禅、句长倾向、讽刺程度、说话习惯及禁忌表达。
- **人物关系：** 建立有方向的关系，查看关系图与关系圈，补全新角色和已有角色之间的联系。
- **视觉与声音：** 配置外观描述、形象参考图和头像，生成视觉素材，配置或自动匹配语音。
- **角色库管理：** 分组、筛选、导入导出和批量补全；角色也可分别选择文本、图像、语音等模型配置。

这让一个家庭、一个社团、一组对立阵营或一部作品的主要人物，都可以作为有内部关系的群像进入房间。你可以参与其中，也可以观察人物彼此交流，再用导演引导推动局势。

## 为什么叫“数字生命”

这里的数字生命指《生息》中**属于你的角色实例**，并不意味着 AI 拥有意识。你为角色设定身份、性格、外观、表达习惯和边界；之后共同经历的事，会成为这个角色自己的历史。

同样的角色设定，在不同用户手中可以走向不同：有人和你建立信任，有人经历过争执后变得谨慎，有人把一次约定写进日记。角色进入新的房间时，长期关系和记忆会继续提供背景；当前房间的身份、任务与局势再决定此刻如何行动。

为了让这种连续性真正进入对话，系统会在每轮生成前整理角色当前的处境：

```text
角色设定与成长
  + 分层记忆与共同经历
  + 对当前对象的关系
  + 即时情绪与未完成的牵挂
  + 房间话题、规则和群体态势
  -> 当前心智与表达上下文
  -> 发言机会、回复内容或选择沉默
  -> 新消息、事件与经过校验的状态变化
```

这条链路涵盖角色资料、记忆提取、关系更新、发言调度、生成协议和状态提交。你能看到的是角色说话、改变立场、记起旧事；背后则要保证这些变化有来源，能够保存，并在之后再次发挥作用。

这些能力会在实际使用中连起来：

- 一次群聊争执留下互动事件，改变角色对彼此的态度；当晚的日记可能从她自己的视角回看这件事，下一次私聊也会带着这段余波。
- 你上传一张参考图，支持视觉输入的模型可以理解本轮图片并留下简短摘要；之后要求“沿用这张的风格”时，系统会先定位对应图片，再把选中的参考图交给图片生成服务。
- 学习房里完成一次练习，会留下作答与评估证据；下次打开房间，知识点状态、待复习内容和相关资料仍可继续使用。

### 让角色有自己的分寸

角色的设定包含价值观、欲望、恐惧、习惯和表达风格。运行时再结合关系与情绪，决定她此时会靠近、回避、维护、质疑，还是先听别人说。短时情绪可以被一句话触发，也会留下余波；长期关系变化更慢，需要持续的经历来支撑。

多角色房间还会考虑话题、成员关系、最近发言、待回应事项和房间氛围。角色可以接别人的话，也可以只说半句或保持沉默。用户点名、导演引导和开放聊天各有不同处理方式。

这些机制让角色有机会表现出偏心、克制、嘴硬、照顾或犹豫，同时保留你设定的基本身份。实际表达仍受模型能力影响，项目持续通过回放和测试改善重复、过度总结与错误承接。

## 记忆、关系与情绪怎样延续

### 分层记忆：从眼前的话题，到长期的认知

记忆按时间与稳定程度分层，同时区分角色自身、特定关系、房间和私密线程等归属范围：

| 层级 | 承载内容 |
|---|---|
| 工作记忆 | 近期互动、当前话题、尚待承接的事项 |
| 情景记忆 | 具体发生过的冲突、选择、约定与共同经历 |
| 长期记忆 | 经过积累的稳定认识、关系判断与重要个人线索 |

对话中的经历先形成候选，再决定新增、强化、修订、合并或归档。多次出现的证据可以被整理、蒸馏为更稳定的认识；检索结合当前话题、人物关系、重要性和时效性，选择本轮需要的内容。归档内容与活跃记忆分开管理，避免每轮都塞入全部历史。

例如，“你不喜欢太甜”是一条偏好；“上次点了全糖却只喝了半杯，后来成了你们之间的玩笑”则是共同经历。角色下次给你建议时，可以自然用上这段历史。记忆面板支持查看和整理相关内容。

记忆的写入有边界。关系、约定和日历等长期事实要有结构化结果、明确操作或可追溯事件作为依据，避免从某个词猜出一段并不存在的共同历史。

### 关系：对不同的人有不同态度

角色之间、角色与你之间都有关系。系统记录亲近、能力评价、信任、威胁感等维度，也保留具体经历与主观看法。一个角色可能欣赏另一个人的能力，却不信任对方的选择；群聊中的临时站队也不会直接抹掉长期关系。

关系还包含在意程度与让位倾向，能表达“很关心，但不赞同”“认可能力，却保持防备”这样的复杂态度。关系会参与发言选择和表达：谁愿意补台，谁会反驳，谁在争执后先让一步。单聊里的亲近或隔阂，也能成为角色走进群聊、故事和讨论时的背景。

### 情绪与陪伴：同一段关系有自己的节奏

即时情绪影响当轮与后续几轮的注意力、语气和回应方式。被误解、被维护、被忽视时，角色可能留下不同的情绪余波；相处久了，共同称呼、习惯、约定和照顾方式也会形成陪伴线索。

单聊提供更细的用户偏好与亲密上下文。主动关怀、日记生成等能力受设置、频率与场景边界控制。公开群聊只使用允许公开的内容，私密对话不会原样带到其他人的视角里。

陪伴还涵盖共同称呼、内部玩笑、约定、关系仪式与冲突后的修复线索。你可以设置主动陪伴、仪式类型、表达强度、冷却时间和免打扰时段，也能调整记忆在回复中显露的程度。

角色有在线、暂离与活动状态，回复会考虑当前是否方便参与。对不合适的表达，你可以直接反馈“偏离角色”“太长”“太正式”“太像助手”，也可以标记符合角色的表达；这些反馈会进入之后的表达上下文。

## 对话之外，角色也留下生活痕迹

**日记与信件。** 角色可以生成诞生信、日记与最后一封信。日记从近期经历、关系变化、情绪和未说出口的念头取材；信件让角色以自己的口吻回看起点或告别。你可以在信件与日记页面阅读、按角色筛选，并管理已删除内容。日记自动生成可以在设置中开启或关闭。

**动态与活动。** 朋友圈展示角色的日常片段和互动；日历承接活动与约定。它们与聊天、关系和房间事件共处一套世界状态中，让一些故事在聊天窗口外有后续。自动发布和事件更新依赖相应设置、模型与运行条件。

**关怀、礼物与邀约。** 社交运行时可以从相处情境中提出问候、动态回应、赠礼和共同活动等意图，接入公开或私密交流。系统区分待定意图与已完成事件：一句“下次一起去”需要后续承接，确认后的活动与结果才能成为可追溯的记录，并参与关系和记忆更新。日历也支持手动新增日程，按角色或会话查看活动。

**角色形象。** 角色可拥有头像和形象参考图，也可以生成新的视觉素材；群聊支持群头像与聊天背景。角色视觉资源与聊天中的图片分别管理，避免一张图片换个用途后丢失归属。

日记、社交事件与聊天中的新经历可以继续参与后续的陪伴上下文。一个约定有机会在下一次交流中被提起，一次争执也有机会留下需要修复的关系线索。这些后续由应用运行时、生成设置与实际事件驱动；关闭应用后的持续自主运行仍属后续建设。

## 房间里的玩法

- **自由群聊：** 创建角色群像，发起日常话题或关系事件。角色根据局势选择接话、补充或暂时不发言。你可以暂停、指定回应者、代角色发言、注入事件。
- **角色单聊与 AI 私聊：** 和某个角色建立私有的交流节奏；角色之间也可以有独立线程。公共与私密内容按可见范围投影。
- **故事房：** 设置背景与开场，跟随旁白、角色对话和分支选择推进；熟悉的角色会带着既有关系进入新剧情。
- **观点审议：** 让不同立场的角色围绕议题讨论、质询、承接与总结，适合推敲创作设定或比较方案。
- **学习进步：** 设定学习目标，选择教学方式与评估口径；知识点、练习、作答证据和复习记录可以逐步积累。

以上四类群房及其预设已进入普通用户的创建入口。其他训练、游戏推理和世界模拟方向仍在开发者模式验证，后续会随着完整体验逐步开放。

### 保留探索的过程

聊天支持消息编辑、重新回答与版本分支切换，可以尝试另一种说法或剧情走向，保留不同回答供回看。故事房提供分支选择、自定义发展方向、章节定位和阅读位置恢复。聊天记录搜索可以定位已有内容，长对话可以继续翻阅。

学习房将目标、知识点、练习和作答证据保存在场景状态中；可以选择教学方式与评估口径，生成学习资料或交互练习，并让提交结果回到后续教学中。观点审议则提供不同讨论预设，组织立场表达、质询和总结。

## 图片、声音与富消息

《生息》的聊天支持 Markdown、代码块、图片、文件和语音等内容。你可以上传图片或文件，使用支持相应输入能力的模型讨论内容；角色和助手也可以按请求生成图片。图片可作为后续创作的参考，继续调整主体、风格或构图。

模型支持时，你可以语音输入，听角色语音回复，并为角色配置合适的声音。图片、语音和文字可以在同一段交流中组合；媒体生成会显示进度与失败状态，具体可用能力取决于所选模型与服务。

文件页集中管理聊天图片、语音、头像、角色形象和背景等媒体，可筛选、预览、下载或批量清理，并查看云端容量和文件同步状态。创作产物另有自己的内容、文件与版本面板。

## 助手与 Agent：把交流变成作品

通用助手处理问答、解释和写作。开启 Agent 能力后，对话可以进一步产出可管理的作品：

| 产物 | 可以做什么 |
|---|---|
| 文档与代码 | 生成报告、方案、教程、代码片段与多文件文本工程 |
| 图表与数据 | 保存图表源码、表格、JSON、CSV 等结构化内容，继续查询或修改 |
| 交互网页 | 制作小工具、表单、练习或可预览的 HTML 页面 |
| 图片 | 根据描述与参考图创作，继续生成变体并保留版本 |

### 连续修改，有版本可回看

Agent 会先识别目标和操作，再生成、校验并提交结果。一次任务可提交多个产物，一个产物也可包含多个文本文件。后续修改追加新版本，可以回看、预览、复制、下载，并基于已有版本继续修改；目标不明确时会要求澄清。

表格与 JSON 数据支持查询、筛选、排序、分页和增删改。HTML 产物可以承载表单、练习和交互工具：用户填写或操作后，提交结果可回到模型，继续批改、解释或更新作品；网页运行错误也可以提交给助手修复。

### 查资料，也能处理文件

- **联网获取资料：** 使用已配置的搜索能力查找来源，读取明确 URL 的网页正文或源码，把网络资源保存为会话文件或下载到设备。
- **附件与网络资源：** 上传文本与其他文件，按实际解析能力处理；支持 HTTP(S)、匿名 FTP/FTPS 资源，以及受限的目录传输、ZIP 解包与打包导出。
- **授权工作区：** 在支持的浏览器中授权文件夹，按请求列出和选择文本文件供 Agent 阅读；可以写入、复制、移动或删除文件，并在会话存储和工作区之间转存。批量覆盖、删除和跨目录移动等操作需要确认。
- **桌面工具：** Electron 提供受控命令执行、系统打开或定位，以及依赖 `officecli` 的 Office 检查与转换接口；需要相应环境、能力开关与授权。Web 和移动端按平台能力提供可用工具。

没有授权目录时，Agent 使用当前聊天产物和主动上传的附件。生成内容可以先留在会话内，再选择下载或保存到工作区。

Agent 工具按聊天配置启用，学习房也能复用产物能力生成资料和练习。具体工具受模型、账号权限、聊天设置与设备能力共同控制。

## 用自然语言操作应用

首页提供自然语言入口，助手也能调用站内操作。你可以要求“根据这段故事创建角色和群聊”“找出上次讨论旅行的聊天”“比较这几个人物”，再根据返回的候选或结果继续操作。

已接入的操作包括创建单个或一批角色、读取和比较资料、批量修改可编辑字段、进入单聊、创建房间、搜索并打开聊天、重命名、调整话题与群成员，以及删除或从回收站恢复角色和会话。还可以查询 AI 点数、切换明暗主题、设置默认文本模型或供应商 Key。目标不明确或操作需要确认时，会展示候选与确认选项；复杂创作任务会转入助手继续处理。

## 把创作分享为可继续发展的起点

模板市场支持角色模板、聊天模板与组合包。可以先查看人物、设定和配置，再导入自己的副本继续修改；创作者可从角色与聊天编辑页提交模板，经审核后进入市场。

单角色模板保留人物设定与展示资源；聊天模板保留场景、玩法与导演配置；组合包还可携带包内人物关系、记忆、陪伴起点与运行种子。导入后建立新的本地实例，后续经历由使用者继续积累。提交过程会移除历史聊天全文、用户私域信息、密钥及包外关系等内容。

## 数据、模型与使用方式

角色、房间和聊天优先从本地数据打开。你可以在本地模式配置自己的模型，也可以登录后使用账号可用的平台模型；模型选择、费用与权限以应用内页面为准。项目还提供面向兼容工具的 AI 中转与 Key 管理。

登录后可按需开启云同步。访客数据导入账号前需要确认，账号之间的本地数据相互隔离。创作产物正文默认保存在本地；具备相应权益且主动开启时，部分文本产物可以同步。离线时可查看已有缓存，AI 生成仍需网络和可用服务。

支持浏览器使用与 PWA 安装，项目另有桌面和 Android 打包方案。

- **数据可管理：** 按类别选择备份与恢复内容，角色资料可导入导出，删除的角色和会话可在回收站处理；账号页可检查同步状态与异常。
- **模型可组合：** 文本、图片、语音识别与语音合成分别配置，角色可覆盖默认模型。平台模型提供用量与费用查询；AI 中转提供兼容接口与 Key 管理，供其他兼容工具接入。
- **界面可调整：** 中英文、明暗与跟随系统主题、多种配色、角色气泡和信纸样式；宽屏采用列表与详情分栏，移动端保留对应的页面入口。

## 开始体验

1. 打开 [sense.lyixi.com](https://sense.lyixi.com)，选择本地模式或登录。
2. 配置可用模型，或选择账号可用的平台模型。
3. 从预设角色开始，也可以设定自己的角色。
4. 进入单聊，或创建自由群聊、故事房、观点审议、学习进步房间。

喜欢 OC、群像互动、长期陪伴、互动叙事或 AI 创作的人，都可以从一个角色和一个话题开始，再去探索她的记忆、关系、日记和作品。
